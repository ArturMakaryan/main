# Haye.bet

Static starter project for the Haye.bet brand surface.

Open `index.html` directly in a browser:

```bash
open "/Users/artur/Documents/New project/Haye.bet/index.html"
```

Files:

- `index.html` contains the preview markup.
- `styles.css` contains the responsive interface styling.

CDN format after pushing to GitHub:

```text
https://cdn.jsdelivr.net/gh/ArturMakaryan/main@COMMIT/Haye.bet/styles.css
```
